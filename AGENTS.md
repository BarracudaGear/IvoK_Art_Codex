# Artist Portfolio — Codex Project Instructions

This is a visual artist portfolio website inspired by kehindewiley.com.

## Stack
- Vanilla HTML, CSS, JavaScript only
- No frameworks, no build tools, no npm
- Opens directly in a browser

## File Structure
- index.html
- css/style.css
- js/main.js
- images/ (empty — placeholder src paths only)
- AGENTS.md (this file)

## Design Tokens
- --black: #0a0906
- --near-black: #111009
- --gold: #c9a96e
- --gold-light: #e2c99a
- --cream: #f0e8d8
- --warm-grey: #a09880
- --text: #d8cfc0
- Fonts: Cormorant SC (headings), Cormorant Garamond (body/quotes), Jost (nav/labels) — Google Fonts

## Coding Rules
- Always use CSS variables, never hardcode hex values
- All images use <img> tags pointing to images/ folder
- Add loading="lazy" to all images except the hero
- Descriptive alt text on every image
- Keep all name placeholders as "Artist Name" until told otherwise
- Use semantic HTML throughout
